PROJECT SPECIFICATION // 04 ♦ HARDWARE SYNTHESIS
PROJECT // 04 Hardware & Verilog

Interactive Digital Voting Machine

Verilog HDL Hardware Logic Architecture • EDA Synthesis

A digital voting machine hardware architecture developed using Verilog HDL, featuring synchronized vote counting, button debounce filtering, and instantaneous winner detection.

  • Synchronous sequential logic with clock gating and reset assertions.
  • Multi-candidate vote accumulation registers with overflow protection.
  • Digital comparator circuitry for instantaneous winner identification.
  • Validated through testbench simulation vectors verifying edge tally conditions.
