# Aashi Srivastava — Personal Portfolio & Field Archive

A bespoke, responsive personal portfolio website crafted for **Aashi Srivastava**, 2nd-year B.Tech Computer Science Engineering (Artificial Intelligence & Data Science) student at **Shri Ramswaroop Memorial University (SRMU), Lucknow**.

Designed around the **Vintage Editorial Meets Modern Technology** concept: resembling an old luxury magazine redesigned for a modern computer science undergraduate.

---

## ✦ Color Palette

Strictly configured to the authentic luxury vintage editorial scheme:
- **Warm Ivory / Aged Paper:** `#F4EFE4` (Main background)
- **Deep Burgundy:** `#632D38` (Primary editorial accent, buttons, headings)
- **Muted Olive:** `#77785B` (Secondary accent, status badges, chips)
- **Dark Brown:** `#342B27` (Primary text & deep ink typography)
- **Soft Beige:** `#DED3C1` (Cards, borders, subtle dividing rules)

---

## ✦ Typography Hierarchy

- **Headings & Display:** `Cormorant Garamond` & `Playfair Display`
- **Body Text:** `DM Sans` (Clean, legible modern sans-serif)
- **Editorial Labels & Metadata:** `Space Mono`

## ✦ How to Run Locally

1. **Double-click `index.html`** in any modern web browser (Chrome, Edge, Firefox, Safari).
2. Or run via Python in your terminal:
   ```bash
   python -m http.server 8000
   ```
   and navigate to `http://localhost:8000`.
